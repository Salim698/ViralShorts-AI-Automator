# Code de Conduite

Dans l'intérêt de favoriser un environnement ouvert et accueillant, nous nous engageons à faire de la participation à ce projet une expérience exempte de harcèlement pour tous.

## Nos Standards
- Faire preuve d'empathie et de bienveillance.
- Être respectueux des différentes approches de code.
- Accepter les critiques constructives sur la structure des workflows.
