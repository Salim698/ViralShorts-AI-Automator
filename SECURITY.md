# Politique de Sécurité

## Faille de sécurité ou secret exposé
Ce projet manipule de nombreuses clés d'API tierces (Gemini, ElevenLabs, Pexels, CloudConvert). 

Si vous trouvez un token API exposé dans le code source ou l'historique des commits, **NE CRÉEZ PAS D'ISSUE PUBLIQUE**. Veuillez me contacter directement ou utiliser le système d'Advisory privé de GitHub pour que je puisse révoquer la clé immédiatement.
